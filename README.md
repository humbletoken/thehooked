# 🎣 Hooked — кооперативная рыбалка в Telegram

Мультяшная 2D-рыбалка в виде Telegram Mini App. Бот: **@HookedGame**.

- соло-режим и комнаты на **до 5 игроков** (публичные — видны в списке, приватные — вход по коду или ссылке-приглашению);
- **лицензия рыбака** — стартовый квест (3 заброса, 3 рыбы, продажа улова, экзамен из 4 вопросов); до неё доступна только учебная рыбалка на озере;
- **4 локации** (озеро, река, болото, море) со своими рыбами — всего 31 вид, включая 3 сезонные;
- **наживки** (расходуются по одной за заброс) и **снасти** (леска, крючки), 5 удочек;
- рабочая механика: заброс (сила = глубина) → поклёвка → подсечка → вываживание с натяжением лески;
- персонаж: выбор пола со своими типами лица, кожа, причёски, одежда, головные уборы, аксессуары, **тату и макияж**;
- **сезоны и рыболовный пропуск** на 30 уровней с бесплатной и премиум-веткой (премиум — 100 ⭐ Telegram Stars). Сезон 1 — **Goth**: готическая одежда, причёски, тату, макияж, эмоции, эффекты заброса, позы, скины удочек; сет **Kai Angel** — 15 уровень премиума, сет **9mice** — 30 уровень;
- **задания** ежедневные, еженедельные и особые сезонные — дают опыт пропуска;
- **события**: ежедневный час клёва, турнир выходного дня на самую тяжёлую рыбу, ночь летучих мышей, босс сезона в кооп-комнатах;
- **рыболовный дневник** (описания, рекорды веса и условия, при которых пойман рекорд), **достижения и титулы**;
- **домик рыбака**: мебель, аквариум с рыбками из дневника, трофеи на стене, приглашение друзей в гости;
- **обмен и подарки** (рыба из садка, наживка и вещи из магазина), **сезонный магазин** за монеты, **архив сезонов**;
- процедурные звуки природы (вода, ветер, птицы, сверчки ночью), спокойная музыка и игровые эффекты;
- смена дня и ночи по местному времени, анимированный экран загрузки, учёт безопасных зон Telegram;
- бот: меню из двух цветных кнопок («Играть» и «Как играть»), премиум-эмодзи из набора [tgiosicons](https://t.me/addemoji/tgiosicons), админ-панель `/admin`.

## Структура

```
bot.js              — ВСЁ серверное: сайт + API + WebSocket-комнаты + SQLite + Telegram-бот
public/index.html   — мини-приложение
public/css/style.css
public/js/data.js   — данные игры (рыбы, удочки, предметы, правила) — общие для сервера и клиента
public/js/art.js    — векторные модели: персонажи, рыбы, удочки, иконки
public/js/scene.js  — сцена озера (canvas)
public/js/game.js   — механика рыбалки и HUD
public/js/audio.js  — звуки и музыка (WebAudio, без файлов)
public/js/net.js    — API/WebSocket + офлайн-режим
public/js/screens.js — лицензия, пропуск, задания, события, домик, обмен, архив, стиль, достижения
public/js/app.js    — меню, экраны, кастомизация, комнаты
```

## Запуск

Нужен Node.js **22.13+** (используется встроенный модуль `node:sqlite`, нативные зависимости не нужны).

```bash
# заполните в .env как минимум BOT_TOKEN, DOMAIN и ADMIN_IDS
npm install
npm start
```

### Docker

`.env` в образ не копируется — настройки передаются при запуске.

```bash
docker build -t hooked .
docker run -d --name hooked --env-file .env -p 3000:3000 -v hooked-data:/app/data hooked
```

или `docker compose up -d --build`.

Сайт должен быть доступен по **HTTPS** на домене из `DOMAIN` (например, через nginx/Caddy/Cloudflare перед портом 3000). Не забудьте проксировать WebSocket по пути `/ws`.

## Настройка бота в @BotFather

1. `/newbot` → получите токен, впишите в `BOT_TOKEN`.
2. `Bot Settings → Configure Mini App → Enable Mini App` → укажите `https://ВАШ_ДОМЕН/` — так заработают ссылки вида `t.me/HookedGame?startapp=room_XXXXX` (приглашения в комнату).
3. (необязательно) `Bot Settings → Inline Mode` — чтобы приглашать друзей через `@HookedGame` в любом чате.
4. Кнопку меню «Играть» и команды бот выставит сам при запуске.

### Премиум-эмодзи и цветные кнопки

Кнопки меню используют поле `style` (`success` — зелёная, `primary` — синяя, `danger` — красная) и `icon_custom_emoji_id`.
Иконки бот при старте берёт из набора `tgiosicons` через `getStickerSet` и подбирает по эмодзи-тегу каждой иконки.
Telegram показывает премиум-эмодзи от бота, только если у **владельца бота есть Telegram Premium** (или куплен юзернейм на Fragment).
Если это недоступно, бот автоматически переключится на обычные эмодзи. Команда `/emoji` (для `ADMIN_IDS`) покажет, какие иконки подобраны;
любую можно заменить через `EMOJI_IDS`.

### Премиум-пропуск и Telegram Stars

Премиум-ветка сезона стоит **100 ⭐**. Игра запрашивает у сервера счёт (`createInvoiceLink`, валюта `XTR`, provider token не нужен)
и открывает его через `Telegram.WebApp.openInvoice`. Бот проверяет счёт в `pre_checkout_query` (тот ли игрок, сумма, текущий сезон,
есть ли лицензия и не куплен ли уже премиум) и выдаёт пропуск только после `successful_payment`; повторные уведомления о платеже не учитываются.
Для вопросов по оплате есть команда `/paysupport` (контакт задаётся в `SUPPORT_CONTACT`).

### Админ-панель

`/admin` работает только для Telegram ID из `ADMIN_IDS`: статистика, поиск игрока по ID или @username, выдача и снятие
премиум-пропуска текущего сезона, начисление монет, список платежей Stars и возврат (`refundStarPayment`).

### Обновление существующей базы

При первом запуске новой версии миграция базы один раз **сбрасывает лицензию у всех игроков** — монеты, улов, дневник,
удочки, одежда и уровни сохраняются. Игроки снова проходят квест лицензии.

## Переменные окружения

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен бота |
| `DOMAIN` | домен сайта (https) |
| `BOT_USERNAME` | юзернейм бота, по умолчанию `HookedGame` |
| `APP_SHORT_NAME` | короткое имя Mini App для ссылок `t.me/<бот>/<имя>` (необязательно) |
| `PORT` | порт веб-сервера, по умолчанию 3000 |
| `BOT_MODE` | `polling` (по умолчанию) или `webhook` |
| `WEBHOOK_SECRET` | секрет пути вебхука (по умолчанию выводится из токена) |
| `DB_PATH` | путь к файлу SQLite |
| `START_COINS` | монеты на старте |
| `EMOJI_PACK` / `EMOJI_IDS` | набор премиум-эмодзи / ручная замена ID |
| `ADMIN_IDS` | Telegram ID админов через запятую (доступ к `/admin` и `/emoji`) |
| `SUPPORT_CONTACT` | контакт поддержки по оплате для `/paysupport` |
| `ALLOW_GUEST` | вход без Telegram (только для отладки) |

## Офлайн-демо

Откройте `public/index.html` прямо из папки (двойным кликом) — игра запустится в офлайн-режиме: прогресс хранится в браузере,
соло-рыбалка, лицензия, магазин, локации, пропуск (бесплатная ветка), задания, домик, стиль и достижения работают локально.
Только онлайн: покупка премиума за Stars, обмен и подарки, гости в домике, таблица турнира и кооп-босс.
Параметр `?demo=1&screen=coop` показывает кооп-комнату с ботами
(другие значения `screen`: `home custom shop wear collection keepnet info profile rooms create fish game aim reel catch pass quests events house archive style ach`; `hour=22` — ночь).
